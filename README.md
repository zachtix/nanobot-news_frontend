# Nano Analysis — frontend

หน้าเว็บของ Nano Analysis (ชื่อเดิม Crypto News Hub) — อ่านข่าวที่รวมจากหลายแหล่ง (พร้อมอ้างอิงทุกแหล่ง), วิเคราะห์ข่าวรายข่าวและภาพรวมตลาดด้วย AI, วิเคราะห์กราฟเหรียญด้วย AI พร้อมทดสอบย้อนหลัง, จัดการแหล่งข่าว, ตั้งเวลาดึงข่าว, ดูการใช้ token/เครดิต AI และตั้งค่า API key / โมเดล / system prompt

React 19 · Vite · React Router · Tailwind CSS v4 · shadcn/ui · TanStack Table · Recharts · Vitest + Testing Library

ต้องใช้คู่กับ API จาก repo [nanobot-news_backend](https://github.com/zachtix/nanobot-news_backend)

## เริ่มใช้งาน

```bash
npm install
npm run dev        # http://localhost:5175 — proxy /api ไปที่ backend (http://localhost:4000)
```

ถ้า backend ไม่ได้อยู่ที่ `http://localhost:4000` ตั้ง `VITE_PROXY_TARGET` ก่อนรัน เช่น `VITE_PROXY_TARGET=http://localhost:5000 npm run dev`

| คำสั่ง | |
|---|---|
| `npm run dev` | dev server |
| `npm test` | เทสทั้งหมด (jsdom) |
| `npm run typecheck` | ตรวจ type |
| `npm run build` | typecheck + build เป็น `dist/` (แยกไฟล์ต่อหน้า และ React แยกเป็นไฟล์ของตัวเอง) |

| **ความแม่นของ AI** | 🔒 เฉพาะผู้ดูแลระบบ · % ที่คำทำนายถูกจริงหลังข่าว (+1 / +4 / +24 ชม. เทียบ BTC) · แยกตามประเภทเหตุการณ์ / ความมั่นใจ / ทิศทาง / สินทรัพย์ / สภาพกราฟ (RSI, divergence, MACD, EMA200 ตอนข่าวออก) · ข้อความสถิติที่ส่งให้ AI ตอนนี้ · คำทำนายทีละรายการ · สลับวิเคราะห์รายข่าว/ตลาด |
| **ตั้งค่า** | 🔒 เฉพาะบัญชี Nanobot ที่ role เป็น ROOT / SENIOR / ADMIN · ตั้งเวลาดึงข่าวอัตโนมัติ (preset หรือ cron) + สวิตช์ "แปลทันที" / "วิเคราะห์ทันที" หลังดึงข่าว (ค่าเริ่มต้นปิด) · เลือกผู้ให้บริการ AI (OpenRouter / Anthropic API) · API key ของแต่ละเจ้า + management key · เลือกโมเดลแยกตามผู้ให้บริการ (ค้นหา + ราคา) · system prompt ทั้ง 5 งาน พร้อมตัวอย่างข้อมูลที่ส่งไป (role: user) · แสดง/ซ่อนชื่อโมเดล |

- **ล็อกอินด้วยบัญชี Nanobot** (`/login`) — ยิงตรงไปที่ Nanobot member API แบบเดียวกับ member-frontend (`POST /v1/auth/login` → `/v1/auth/me` เอา role, `/v1/auth/refresh-token`, `/v1/auth/logout` พร้อม `x-api-key`) อยู่ที่ `src/api/nanobot.ts` · ตั้ง `VITE_API_URL_MEMBER` / `VITE_API_KEY_MEMBER` ใน `.env` (ดู `.env.example`) · member API ต้องเปิด CORS ให้ origin ของเว็บนี้ · ปุ่ม "เข้าสู่ระบบ" / เมนูบัญชี (อีเมล + role + ออกจากระบบ) อยู่มุมขวาบน · token เก็บใน `localStorage` และแนบ `Authorization: Bearer` ไปกับทุก request ถึง backend (`src/api/client.ts`) — token หมดอายุ → ขอใหม่ที่ Nanobot อัตโนมัติ 1 ครั้ง · หน้า**วิเคราะห์ตลาด**และ**วิเคราะห์กราฟ**ต้องล็อกอิน (`RequireSignIn`) · หน้า**แหล่งข่าว**, **การใช้ AI**, **ความแม่นของ AI** และ**ตั้งค่า** เข้าได้เฉพาะผู้ดูแลระบบ (role ROOT / SENIOR / ADMIN, `RequireStaffRole`) และเมนูของหน้าเหล่านี้ซ่อนจากลูกค้า · ราคาเครดิตที่แสดงบนปุ่มอ่านจาก `/api/health` (`useCreditPrices`) ยังไม่ล็อกอิน → ไปหน้าล็อกอินแล้วกลับมาที่เดิม, role อื่น → แจ้งว่าไม่มีสิทธิ์ · backend ตรวจ token + role กับ Nanobot ซ้ำทุก request ของ API เหล่านี้ · หน้าอื่นยังเปิดให้ทุกคน
- **ภาษา TH / EN** สลับได้ที่มุมขวาบน (จำค่าไว้) — ข้อความทั้งหมดอยู่ใน `src/i18n/messages.ts`
- **API** ทั้งหมดผ่าน `src/api/client.ts` · type ของข้อมูลอยู่ใน `src/api/types.ts`

## โครงสร้าง

```
src/
├── api/          client + types ของ backend API
├── pages/        หน้าหลักแต่ละเมนู (โหลดแยกเมื่อเปิดครั้งแรก ยกเว้นหน้าข่าว)
├── components/   component ของแอป (DataTable, Pagination, NewsCard, …) + ai/ market/
│   └── ui/       component ของ shadcn/ui
├── context/      สถานะการดึงข่าว (poll), health ของ backend, บัญชีที่ล็อกอิน (AuthContext)
├── i18n/         ข้อความ TH / EN
├── utils/        format ตัวเลข/วันที่/เครดิต
└── test/         setup + helper สำหรับเทส
```

## UI

- **shadcn/ui + Tailwind CSS v4** — ใช้ component ของ shadcn ทั้งหมด (Button, Card, Table, Select, Switch, Tabs, Dialog/AlertDialog, Popover + Command, Collapsible, Tooltip, Sonner toast, Chart ฯลฯ) อยู่ใน `src/components/ui/`
- **ธีม Nanobot สว่าง/มืด** — สีหลัก Nanobot blue (`#0076D1` โหมดสว่าง, `#06BAFC` โหมดมืด), พื้น slate, ฟอนต์ Onest + Prompt, มุมโค้ง 12px · ตั้งค่าที่ `src/index.css` (CSS variables ของ shadcn) · ปุ่มธีมมุมขวาบน: สว่าง / มืด / ตามระบบ (จำค่าไว้)
- **สีกราฟ** — ผ่านการตรวจ contrast และตาบอดสี (CVD) แยกชุดสำหรับโหมดสว่างและมืด · สีผูกกับประเภทงาน (ตรวจข่าวซ้ำ / แปล / ติดแท็ก / วิเคราะห์ข่าว / วิเคราะห์ตลาด; วิเคราะห์กราฟใช้สี info; ทดสอบการเชื่อมต่อเป็นสีเทา) ไม่เปลี่ยนตามลำดับ
- **ตาราง** (`DataTable`, TanStack Table) — ทุกคอลัมน์มีความกว้างขั้นต่ำ · ตารางกว้างเกินจอจะเลื่อนแนวนอนแทนการบีบ · ลากเส้นแบ่งหัวคอลัมน์เพื่อปรับความกว้าง (ย่อต่ำกว่าขั้นต่ำไม่ได้), ใช้ปุ่ม ←/→ บนเส้นแบ่งได้, ดับเบิลคลิกเพื่อรีเซ็ต · ความกว้างจำไว้ในเบราว์เซอร์ (`localStorage` ต่อตาราง) · **แบ่งหน้า**: เลือกจำนวนต่อหน้า 10 / 20 / 50 / 100 (ทุกตารางและรายการข่าวเริ่มที่ 10 · จำค่าไว้แยกแต่ละตาราง), ปุ่มหน้าแรก/ก่อนหน้า/ถัดไป/สุดท้าย และบอก "1–20 จาก N" — ใช้กับข่าว, แหล่งข่าว, ประวัติการดึงข่าว, การเรียก AI และตารางรายวัน/แยกโมเดล · ถ้าจอกว้างกว่าตาราง คอลัมน์หลักจะขยายเต็มพื้นที่ · ตารางที่กว้างเกินจอมี**แถบเลื่อนแนวนอนติดขอบล่างของจอ**ตลอดเวลาที่ตารางอยู่บนจอ (ไม่ต้องเลื่อนลงไปท้ายตาราง) · เนื้อหาที่กางออกของแถว (เช่น ดู prompt) **ตรึงอยู่ในส่วนที่มองเห็น** ไม่เลื่อนซ้ายขวาตามตาราง · ตารางที่กางแถวได้ (ประวัติการดึงข่าว, การเรียก AI) **คลิกตรงไหนของแถวก็กาง/หุบได้** (ยกเว้นปุ่ม/ลิงก์ในแถว หรือตอนลากเลือกข้อความ)
- หน้าอื่นนอกจากหน้าข่าวโหลดแยกเมื่อเปิดครั้งแรก (code splitting) เพื่อให้หน้าแรกโหลดเร็ว
